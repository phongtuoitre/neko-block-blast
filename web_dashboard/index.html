Trận gần đây

Chưa có API công khai cho danh sách trận gần đây. Backend hiện có GET /matches/{match_id} và GET /rooms/{room_code}/active-match, cả hai đều cần xác thực người dùng và thông tin trận hoặc phòng. Dashboard không nhúng thông tin xác thực nên không gọi các endpoint này.

Cloud services

Dịch vụ cloud chính

  • Azure Container Apps Chạy container Nginx phục vụ dashboard tĩnh.
  • Azure API Management Gateway public: https://apim-neko-game-nhom2-2026.azure-api.net/neko.
  • Azure App Service Chạy FastAPI backend hiện có.
  • Azure Database for PostgreSQL Lưu user, phòng, trận và điểm.
  • Azure Blob Storage Lưu file NekoBlockBlast.exe và match result blob.
