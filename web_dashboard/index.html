Cloud services

Dịch vụ cloud chính

  • Azure Container Apps Chạy container Nginx cho dashboard.
  • Azure API Management Đưa các API public ra gateway thống nhất.
  • Azure App Service Chạy backend FastAPI.
  • Azure Database for PostgreSQL Lưu người chơi, trận đấu và điểm số.
  • Azure Blob Storage Lưu artifact và kết quả trận khi backend ghi sự kiện.
